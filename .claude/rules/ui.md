# Правила UI (SPEC §7)

- У каждого экрана четыре состояния: loading / empty / error / offline.
- Цели касания ≥ 44×44 px. Видимый фокус у всего интерактивного.
- Цвета только через токены (`src/styles/tokens.css`), без hex и произвольных цветов Tailwind.
- Основной viewport — 360×740: без горизонтальной прокрутки, нижняя панель не перекрывает фокус.
- Статусы не только цветом: текст или иконка с подписью. У иконок-кнопок есть `aria-label`.
- Тексты на «вы», без канцелярита, глоссарий — SPEC §7.6.
- Новый маршрут добавляется в `tests/a11y/smoke.spec.ts` и `tests/e2e/shots.spec.ts`.
