# 22 ноября 2026 — подключение Alice AI

Владелец предоставил API-ключ Yandex AI Studio для помощника «Компаса». Проверен каталог, открытый владельцем в AI Studio. Секрет сохранён только в `/opt/kompas/.env.prod` на HP с правами 600. Приложение перезапущено из существующего production-образа. Локальные незавершённые правки интерфейса в эту поставку не вошли.

Используется `aliceai-llm-flash`, OpenAI-совместимый Chat Completions API Яндекса и схема авторизации `Api-Key`. В Compose добавлена передача уже поддерживаемой приложением переменной `AI_AUTH_SCHEME`. Прямой пробный запрос с HP получил HTTP 200. Текст, присланный пользователем, не переносился в документацию или историю исходников.

## Ограничения

Действующий лимит — 20 вопросов на пользователя за 24 часа в памяти процесса. При перезапуске он начинается заново. Общий денежный лимит приложения не реализован. Бюджеты Yandex Cloud отправляют уведомления и сами не прекращают вызовы. Формулировки в ранее подготовленном конкурсном PDF о неподключённом провайдере следует обновить перед публикацией итогового файла.
