**Итого за фазу B (23 тикета, 19 сессий GLM + координатор):** ~2,6 млн входных / ~0,44 млн
выходных токенов ≈ **$0,61** (без кэширования; с кэш-хитами < $0,35). Контрольная сверка
реального счётчика не проводилась — сборка OpenCode не отдаёт статистику (см. шапку).

Аналогичный объём на Claude Opus 5.5 по тарифу фазы A (~$5 вход / ~$25 выход за 1 млн)
составил бы ≈ **$16–20** — экономия ≈ порядок 30×. Данные для PDF-отчёта о «маршрутизации
по сложности»: все однотипные эндпоинты по контрактам закрыты дешёвой моделью, ревью
и приёмка — за дорогой (фаза C).
