# Дополнения к `.env.example` (этап C10)

Запись в `.env.example` в сессии C10 запрещена правилами, поэтому готовый блок лежит здесь.
Добавьте его в конец `.env.example` (значения безопасные: секретов нет). Боевые значения — только в `.env.prod` на сервере, в репозиторий не попадают.

```dotenv
# --- Продакшен и демо-контур (C10, D-017) ---
# Домен для Caddy (HTTPS выпускается автоматически). Пусто или ":80" — без HTTPS, только для проверки.
KOMPAS_DOMAIN=
# Публичный адрес приложения с https://. Должен совпадать с адресом, по которому открывают сайт (проверка Origin).
BETTER_AUTH_URL=http://localhost:3000
# Приложение стоит за Caddy, который перезаписывает X-Real-IP (D-005). В production без true не стартует.
TRUSTED_PROXY=false
# Секрет подписи ссылок и QR проверки документов. В production — длинная случайная строка (openssl rand -hex 32).
VERIFY_SECRET=
# Кнопка «Сбросить демо-данные» и ночной пересев. false — выключить на контуре с настоящими данными.
DEMO_RESET_ENABLED=true

# --- ИИ-помощник «Спросить Компас» (C9, D-016) ---
# Выключен по умолчанию. Без ключа работает детерминированный поиск по справочнику.
AI_ASSISTANT=false
AI_PROVIDER_URL=
AI_API_KEY=
AI_MODEL=
```

Для `deploy/docker-compose.prod.yml` дополнительно нужны `POSTGRES_PASSWORD` и `BETTER_AUTH_SECRET` (см. `docs/deploy/CHECKLIST.md`, шаг 3).
