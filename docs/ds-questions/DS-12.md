# DS-12 — решения по семантике успеваемости семестра

Не блокирующие вопросы; решения приняты субагентом DS-12/DS-13 в рамках тикета,
на сид-данных детерминированы. Claude при ревью может скорректировать.

1. **`semester` в query — опционален.** Без параметра берём последний доступный
   семестр студента (max из его enrollments). Валидация: только формат `NNNN-N`
   (regex `^\d{4}-\d{1,2}$`), иначе 422 VALIDATION. Невалидный или пустой — 422.
2. **Существующий формат, но не в списке семестров студента → 404 NOT_FOUND**
   (а не пустой список): «несуществующее = 404» (§3 п.4), и студент не должен
   прощупывать чужие семестры. Список своих семестров — `GradesDTO.semesters`.
3. **`mark` = null, пока не сданы все элементы контроля / есть final_results;
   для `control: credit` всегда null.** Иначе «Неудовлетворительно / F» при
   11,5/50 перед несданным экзаменом противоречит принципу «не стыдим» (SPEC §6.4).
   Оценка появляется только по завершённой дисциплине (final_results).
4. **`maxSoFar`** — «максимум на сегодня» кольца прогресса: Σ wᵢ·100 только по
   СДАННЫМ элементам (Аня: 11,5/50, что и требовал исходник тикета).
5. **`credit.conditions`** — элементы контроля курса, `met = score !== null`;
   `label` — название работы из сида (данные, не авторский копирайт).
   `passed` — null до `final_results` (status = 'passed').
6. **`missedDeadlines`** (вход DS-04) — элементы контроля с `dueAt < now` и без
   оценки. Объективный источник: `assessments` × `grades`, без `deadlines`.
7. **`daysToSession`** — полные календарные дни (МСК) от сегодня до ближайшего
   будущего экзамена по дисциплинам семестра (startOfDay diff); нет будущих
   экзаменов → null.
8. **`averagePreliminary`** — средний итог S по дисциплинам семестра, где есть
   хоть одна оценка, 1 знак.
9. **`risk`** — дисциплина даёт хотя бы одну причину в `status.reasons` (вкл.
   NOT_ADMITTED и DEBT — статус «хуже риска», метка риска тоже ставится).

DS-13: не UUID в `:courseId` → 404 (как в эталоне заявок); `peerGoal` всегда null.
