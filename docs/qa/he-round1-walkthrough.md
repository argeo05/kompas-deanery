- **CW-11 · серьёзность 3 · В3.** Главная цифра сводки — «Средний балл **23.8** предварительно» без шкалы. Первокурсница привыкла к среднему баллу по пятибалльной шкале (4,2) и прочтёт 23.8 как ошибку или как «23 из 100 — всё плохо». Из чего он складывается, понять нельзя (по дисциплинам видны 11.5/50 и 24/30). **Рекомендация:** показывать средний балл по шкале итоговой оценки («≈ 3,6 из 5, предварительно») или убрать до первых итоговых оценок. В любом случае подписывать шкалу.
- **CW-12 · серьёзность 3 · В3.** Цифры про один и тот же риск противоречат друг другу:
  - в сводке «Учёбы» — «для удовлетворительной оценки нужно набрать **больше 70%** оставшихся баллов»;
  - в карточке дисциплины — «„Удовлетворительно“ (3): нужно ещё **43.5 из 50** возможных баллов» (87%);
  - в списке — «Набрано 11.5 из **50** баллов на сегодня», в кольце дисциплины — «11.5 баллов из **100**»;
  - ползунок экзамена «0 из **100**», хотя экзамен весит 50% итога, а «43.5 из 50» — во взвешенных баллах.

  Студентка не может понять, сколько ей нужно на экзамене (на самом деле ≈ 87 из 100). **Рекомендация:** одна формулировка из одного расчёта: «Чтобы получить „удовлетворительно“, на экзамене нужно ≥ 87 из 100». Взвешенные и «сырые» баллы на одном экране не смешивать; знаменатель везде подписывать («на сегодня» / «за семестр»).
