# KLM: время по модели, «до» и «после» (этап C11)

Модельная оценка Keystroke-Level Model (Card, Moran, Newell), не замер на людях. Подробности, допущения и цели §13.5 — в [heuristic-eval.md](heuristic-eval.md#klm-время-выполнения-по-модели).

**Операторы** (классические значения, [R51] в SPEC): K = 0,2 с, P = 1,1 с, H = 0,4 с (не используется), M = 1,35 с. Касание = P + K = 1,3 с. Ожидание ответа системы R = 0 в обоих вариантах. Одна M на экран с выбором и на чтение результата.

**«До»** — путь по качественному описанию реального ЛК МГИМО ([R39], SPEC §2.5): меню, раздел, таблицы. Чисел о реальном ЛК в SPEC нет, путь построен нами, это допущение. **«После»** — фактический путь в Компасе.

| Задача                                                | Касаний «до» | Время «до» | Касаний «после» | Время «после» |
| ----------------------------------------------------- | ------------ | ---------- | --------------- | ------------- |
| 1. Где следующая пара                                 | 4            | 10,6 с     | 0               | 1,35 с        |
| 2. Заказать справку об обучении                       | 9            | 21,0 с     | 4               | 9,25 с        |
| 3. Статус заявки и ответ на уточнение (+ 40 символов) | 5            | 21,25 с    | 3               | 14,6 с        |
| 4. Перенесена ли пара                                 | 4            | 10,6 с     | 0               | 1,35 с        |
| 5. Сколько баллов нужно до «удовлетворительно»        | 5            | 17,3 с     | 2               | 6,65 с        |

Цели §13.5: Q-KLM-1 ✅ (0 касаний, 1,35 с), Q-KLM-2 ✅ (4 касания, 9,25 с), Q-KLM-3 ✅ (3 касания + ввод).
