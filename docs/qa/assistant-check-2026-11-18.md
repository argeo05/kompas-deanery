# Проверка поиска по студенческому справочнику, 18 ноября 2026 года

На первой попытке поиск дал ожидаемый результат для **9 из 16** синтетических вопросов. Для 12 вопросов по темам справочника он первым предложил нужную статью **5 раз**. На всех четырёх вопросах вне справочника ответил, что статьи нет.

Оценщик составил вопросы, ориентируясь только на `slug` и заголовки 25 статей в `content/kb`. Формулировки и ожидаемые ответы зафиксированы до чтения алгоритма, предыдущего набора вопросов и первого запуска. После прогона сверили строки с 45 вопросами прежнего эксперимента. Совпадений после приведения к нижнему регистру и удаления пунктуации не обнаружено. Запросы, ожидания и поисковые правила после фиксации не меняли.

Испытан детерминированный поиск на локальной копии проекта, Node.js 25.9.0. Успех означает, что поиск первым вернул ссылку на подходящую статью либо сообщил об отсутствии статьи по теме. Полноту текста ответа, работу внешней модели и поведение реальных студентов в этом опыте не оценивали. Доля 9 из 16 относится только к приведённым вопросам.

## Зафиксированные вопросы

Засчитывается совпадение первой предложенной статьи с ожидаемой. Для четырёх вопросов по темам вне справочника засчитывается только ответ без найденной статьи (`null`). Порядок строк соответствует порядку испытаний. Каждая строка ниже содержит исходный вопрос и ожидаемый `slug` либо `null`.

## Как повторить

Из корня проекта с установленными зависимостями выполните блок в оболочке. Он сверяет отпечаток и передаёт вопросы прямо в `answerFromKb` вместе с теми же статьями, которые читает `pnpm eval:assistant`. Для результата «нет статьи» требуется ответ `not_found`. Команда выводит номер вопроса, ожидаемый и полученный ответ и отметку совпадения.

````sh
node --import tsx --input-type=module <<'JS'
import assert from "node:assert/strict";
import { createHash } from "node:crypto";
import { readFileSync } from "node:fs";
import { answerFromKb } from "./src/lib/assistant/engine.ts";
import { readKbFiles } from "./db/seed/kb.ts";

const note = readFileSync("docs/qa/assistant-check-2026-11-18.md", "utf8");
const raw = note.match(/^```jsonl\n([\s\S]*?)^```$/m)[1];
const expectedDigest = "145a99fa333cd9fd4bba07d0644b6f00b2bcbf0c334cb565bfcd8b6b58c57a77";
assert.equal(createHash("sha256").update(raw).digest("hex"), expectedDigest);
const questions = raw.trimEnd().split("\n").map(line => JSON.parse(line));
const articles = readKbFiles();
let hits = 0;
for (const [i, [question, expected]] of questions.entries()) {
  const result = answerFromKb(question, articles);
  const actual = result.kind === "answer" ? result.sources[0]?.slug : result.kind;
  const match = actual === (expected ?? "not_found");
  if (match) hits++;
  console.log(i + 1, expected ?? "not_found", actual, match);
}
console.log(`${hits}/${questions.length}`);
JS
````
