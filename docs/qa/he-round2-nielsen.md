# Эвристическая оценка по Нильсену, раунд 2 (свежий взгляд)

Синтетическая экспертная оценка одним оценщиком (ИИ-агент), не исследование с реальными пользователями. Стенд: dev-сервер localhost:3000, БД kompas_dev после пересида (16.11.2026, ночь по Москве). Роли: Аня (anna.demo) и Елена Сергеевна (elena.staff). Устройства: 360x780 и 1440x900, светлая и тёмная темы. Шкала серьёзности Нильсена: 0 нет проблемы, 1 косметическая, 2 малая, 3 крупная, 4 катастрофа.

Что проверялось: вход (пустая отправка, неверный пароль), Сегодня, Расписание, Учёба (3 вкладки), Дедлайны (отметка «Сделал» и возврат), Заявки, форма новой заявки (валидация), карточка заявки, Документы, Поиск (результаты и пусто), Связь с деканатом, Справочник, Уведомления и их настройки, Приватность, Профиль; у сотрудника: очередь, карточка заявки, объявления, новое объявление, изменения расписания, обращения (пусто), профиль. Состояние offline проверено частично (см. ограничения).

Следы в данных: заявки и объявления я не создавал. Менял только настройки уведомлений Ани (категория «Оценки» → «Сразу» → сохранено → возвращено «В дайджест») и отметку «Сделал» у дедлайна (возвращена). Заявка СП-2611-0073 (Анна, «Нужно уточнение») появилась в сиде/очереди не от меня.

## Что сделано хорошо (по эвристикам)

- H1: баннер офлайн с временем данных, «обновлено только что», бейджи «Перенесена 12:40 → 15:20» с цветом, иконкой и текстом, статусный путь заявки.
- H2/H5: «Где забрать» в готовой справке, предзаполнение из профиля, подтверждение публикации объявления с числом получателей, «Вернуть в работу» после «Сделал».
- H9: сообщение при неверном пароле (раскладка, Caps Lock), пустые состояния поиска с двумя выходами («Открыть справочник», «Написать в деканат»).
- H4: единые токены, обе темы читаемы, цели касания не меньше 44 px по визуальной оценке.
- H7: поиск по Cmd+K на десктопе, онбординг можно пропустить.

## Ограничения

- Один оценщик, синтетическая оценка; рекомендуется сведение с другими оценщиками.
- Состояния loading и error специально не вызывались (не было безопасного способа без правки кода); проверены offline (частично, из-за dev без service worker), empty (Документы, Обращения, поиск без результатов, 404) и валидация.
- Параллельно на стенде работали другие оценщики (заявка СП-2611-0073 и изменение статуса не от меня), поэтому часть данных могла меняться.
- В отчёте нет сравнения с раундом 1 (не читал по условию).
