## KLM: время выполнения по модели

Модельная оценка времени опытного пользователя (Card, Moran, Newell), не замер на людях. Коротко то же самое: [klm.md](klm.md).

**Операторы** (классические значения Keystroke-Level Model, см. [R51] в SPEC): K (нажатие клавиши) = 0,2 с, P (наведение; для касания — перенос пальца к цели) = 1,1 с, H (смена устройства ввода) = 0,4 с, M (мысленная подготовка) = 1,35 с. Касание = P + K = 1,3 с. Значения для сенсорных экранов из адаптации [R51] не подставлялись: берём классику, чтобы «до» и «после» считались одной линейкой. H = 0 (пользователь с телефоном не меняет устройство). Ожидание ответа системы R = 0 в обоих вариантах (у реального ЛК оно, скорее всего, больше, так что «до» получается заниженным в пользу ЛК). Вход в систему не считается ни там, ни там (сессия активна).

**Правило M.** Одна M на каждый экран, где нужно найти и выбрать, плюс M на чтение результата; для таблиц с поиском строки и подсчётом вручную — отдельные M.

**«До» — допущения, а не измерение.** В SPEC §2.5 о реальном ЛК МГИМО [R39] есть только качественное описание: главная — новости, почти всё таблицами, на телефоне страница уменьшена, вход по телефону, отдельные пункты «Документы» и «Центр заявок», успеваемость с выбором семестра и вкладками «Экзамены» и «Зачёты». Чисел (касаний, времени) там нет, самого ЛК мы не проходили. Поэтому путь «до» построен нами из этого описания: меню → раздел → таблица. Это оценка по описанию, каждое допущение указано в таблице. Реальный ЛК мог бы оказаться как быстрее, так и медленнее.

**«После» — по фактическому пути в Компасе** (e2e проверяет 4 касания для заказа справки; остальное — по когнитивному проходу раундов 1 и 2).

### Цели §13.5 по KLM

| Цель                                               | Факт                                           | Итог |
| -------------------------------------------------- | ---------------------------------------------- | ---- |
| Q-KLM-1: следующая пара, ≤ 1 касание и ≤ 3 с       | 0 касаний, 1,35 с                              | ✅   |
| Q-KLM-2: заказ справки, ≤ 4 касаний и ≤ 12 с       | 4 касания, 9,25 с                              | ✅   |
| Q-KLM-3: статус и ответ, ≤ 4 касаний + ввод текста | 3 касания (карточка, поле, «Отправить») + ввод | ✅   |

Ограничения. Расчёт по минимальному пути без ошибок; новичок будет медленнее. Для задачи 1 цель «≤ 3 с» относится к чтению ответа, не к запуску приложения. Касание поля ввода в задаче 3 учтено как отдельное, хотя в отчёте раунда 1 оно было включено в «2 касания + ввод».
