# C11 · раунд 1 · Доступность (WCAG 2.2 AA), ручная проверка

Оценщик: независимый эксперт по доступности (субагент). Дата: 16.11.2026.
Стенд: `http://localhost:3000` (dev-сервер, база `kompas_dev`), аккаунты `anna.demo` и `elena.staff` (вход кнопкой «Войти как…»).
Инструменты: Playwright MCP (отдельный браузерный контекст, клавиатура, дерево доступности, `getComputedStyle`, замер пикселей скриншота через canvas). Ширина 360 и 1440 px, дополнительно 320, 640, 720 и 768 px. Светлая и тёмная тема, `prefers-reduced-motion`, офлайн через `context.setOffline`.
Шкала серьёзности по Нильсену: 0 — не проблема, 1 — косметика, 2 — мелкая, 3 — крупная, 4 — катастрофа.
Скриншоты: `docs/qa/shots/round1-a11y/`.

До цели Q-HE-1 (0 нарушений серьёзности 3–4) нужно исправить три пункта. Каждый правится локально: один глобальный стиль ссылок, перенос кнопок в hero и `CardLink` вместо голого `className="card-link"`.
