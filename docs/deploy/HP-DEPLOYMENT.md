## Обслуживание

В `/etc/cron.d/kompas` установлены задания по UTC, часовой пояс сервера UTC. Копирование запускается ежедневно в 03:30 МСК, пересев демонстрационных данных — в 04:00 МСК, HTTPS-проверка — каждые пять минут. Журналы — `/var/log/kompas-backup.log`, `/var/log/kompas-reseed.log`, `/var/log/kompas-health.log`. Docker включён в автозапуск системы. Первый плановый ночной запуск ещё предстоит наблюдать.

Состояние и журналы можно прочитать через обёртку `hp-home-server`, описанную в навыке пользователя. Команды Docker запускать с sudo из `/opt/kompas`, используя `docker compose --env-file .env.prod -f deploy/docker-compose.prod.yml`.

При первом заполнении обнаружено, что сервис tools не получал `VERIFY_SECRET`, нужный для подписи демодокументов. Конфигурация исправлена. Пересев повторён только для новой базы «Компаса».
